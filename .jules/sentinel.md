## 2024-10-14 - Fix Timing Attack in Admin Secret Validation
**Vulnerability:** A timing attack vulnerability existed in the `/api/auth/register-admin` route. The application compared the incoming `secretKey` to the `ADMIN_SECRET_KEY` using standard string inequality (`!==`). This allows an attacker to gradually infer the secret character-by-character based on the time it takes the server to reject the request, potentially bypassing admin authorization.
**Learning:** Standard comparison operators (`==`, `!=`, `===`, `!==`) compare strings character-by-character and terminate upon the first mismatch. For cryptographic secrets, API keys, or verification codes, this early exit leaks information about the secret's structure.
**Prevention:** Always use constant-time comparison functions when comparing secrets. The codebase provides `safeEqual` in `lib/security.ts` (or `crypto.timingSafeEqual`) which ensures the time taken to evaluate the equality is independent of the input contents and length.
