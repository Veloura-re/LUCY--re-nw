## 2024-11-07 - Math.random() Array Shuffling Bias\n**Vulnerability:** Array shuffling using `array.sort(() => Math.random() - 0.5)` provides biased permutations and relies on an insecure RNG (Math.random).\n**Learning:** The sort-based shuffle does not distribute permutations uniformly because JS `.sort()` algorithms are not designed to be given a random comparator. Additionally, Math.random() shouldn't be used in edge routes since it's not cryptographically secure.\n**Prevention:** Use a Fisher-Yates shuffle implementation paired with a secure random number generator, such as the `secureRandomInt` helper provided in `@/lib/security`.
