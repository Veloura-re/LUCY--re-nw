## 2024-05-24 - [CRITICAL] Predictable Pseudonym Generation via Math.random()
**Vulnerability:** The function `generateSanctuaryPseudonym` was generating deterministic anonymous pseudonyms using `Math.random()`, which is a predictable pseudo-random number generator (PRNG) rather than a cryptographically secure one. An attacker who determines the random seed of `Math.random()` could potentially correlate user actions or guess user pseudonyms, which breaches the expected privacy model of the sanctuary mechanism.
**Learning:** Security-sensitive identifier generation, such as anonymous pseudonyms where identity isolation is a core requirement, must always use a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG). Using predictable functions like `Math.random()` exposes users to de-anonymization.
**Prevention:** Removed `Math.random()` usage in `sanctuary-guardrails.ts`. Always utilize `secureRandomInt` (which uses the Web Crypto API `globalThis.crypto.getRandomValues()`) or similar functions specifically designed for secure ID generation when randomized identifiers are required.
