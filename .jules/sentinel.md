## 2024-09-04 - [Remove Hardcoded Secrets]
**Vulnerability:** Found dummy API keys and test secrets used as fallback values for environment variables across multiple API routes (`STRIPE_SECRET_KEY`, `TURNSTILE_SECRET_KEY`, `ADMIN_DEV_RESET_SECRET`).
**Learning:** Using test/dummy keys as fallbacks for missing environment variables creates a critical 'fail open' vulnerability. If the production environment variables are accidentally omitted, the application will silently accept test keys, completely bypassing security protections like Turnstile captchas and administrative authentication. Furthermore, initializing 3rd party SDKs (like Stripe) at the top-level with these dummy keys masks configuration errors and can cause build or deployment issues.
**Prevention:** Never use dummy keys as fallbacks. Instead, strictly validate the presence of required environment variables at runtime (typically inside the request handler or initialization logic) and fail closed (return a 500 Server Error) if they are missing.
