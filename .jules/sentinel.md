## 2024-05-14 - Fix Insecure Fallbacks for Critical Secrets
**Vulnerability:** Several API routes used test keys (e.g., Cloudflare Turnstile dummy keys) or unprivileged keys (e.g., `NEXT_PUBLIC_SUPABASE_ANON_KEY`) as fallback defaults when critical environment variables (`TURNSTILE_SECRET_KEY` or `SUPABASE_SERVICE_ROLE_KEY`) were missing. This creates a fail-open security vulnerability, potentially bypassing intended protections entirely or causing silent privilege drops.
**Learning:** The importance of fail-secure architecture and explicit error handling for missing secrets. When critical secrets are missing, the system should fail securely (e.g., throwing a 500 error) rather than falling back to unprivileged defaults that could mask the configuration error and allow unauthorized access.
**Prevention:** Never provide unprivileged defaults for missing critical secrets. Explicitly check for the presence of required environment variables and throw an error or handle securely if they are missing.
