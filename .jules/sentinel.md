## 2024-06-11 - Hardcoded Secrets in Config\n**Vulnerability:** Hardcoded API Keys and Secrets in `worker-configuration.d.ts`\n**Learning:** This file is used for type generation in wrangler. It should not contain hardcoded secrets, as these can easily leak to version control.\n**Prevention:** Replace the string literals with `string` and manage secrets using environment variables or secret stores.
