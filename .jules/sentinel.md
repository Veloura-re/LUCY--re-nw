## 2024-05-24 - [CRITICAL] Fail-Open Authorization via Missing Environment Variables
**Vulnerability:** Several sensitive endpoints (`/api/cron/backups`, `/api/admin/dev-reset`, `/api/auth/login`) used environment variables for authorization (`CRON_SECRET`, `ADMIN_DEV_RESET_SECRET`, `TURNSTILE_SECRET_KEY`) but did not explicitly verify their existence. In JavaScript, template literals with missing env vars evaluate to `"Bearer undefined"`, allowing attackers to bypass checks by providing that string. Additionally, fallback dummy keys were used which provided a known attack vector or bypassed protections entirely (e.g., Turnstile).
**Learning:** Hardcoded fallbacks for secrets undermine security, and missing environment variables can lead to dangerous "fail open" conditions if not explicitly handled.
**Prevention:** Always check if a sensitive environment variable is defined before using it. If it is missing, fail securely with a 500 Internal Server Error rather than attempting to provide an unsafe fallback or allowing it to evaluate to `undefined`.
