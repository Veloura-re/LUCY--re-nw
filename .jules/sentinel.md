## 2024-11-23 - Privilege Drop Vulnerability in Supabase Initialization\n**Vulnerability:** Found instances where privileged admin clients fallback to `NEXT_PUBLIC_SUPABASE_ANON_KEY` if `SUPABASE_SERVICE_ROLE_KEY` is not set.\n**Learning:** Providing an unprivileged fallback for a privileged client can cause silent privilege drops and fail-open security risks, leading to unexpected behavior and bypasses. Admin clients should fail securely if the necessary keys are absent.\n**Prevention:** Never provide a fallback unprivileged key (like anon key) when initializing administrative clients. Always ensure the privileged key is explicitly present and let it fail securely if missing.
