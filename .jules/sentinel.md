## 2026-09-15 - [CRITICAL] Cloudflare Turnstile "Fail-Open" Dummy Key Fallback
**Vulnerability:** In `app/api/auth/login/route.ts`, the login endpoint fell back to a dummy test key (`1x0000000000000000000000000000000AA`) if `TURNSTILE_SECRET_KEY` was missing from environment variables.
**Learning:** Using a dummy test key as a fallback for missing environment variables creates a "fail-open" vulnerability. In the case of Cloudflare Turnstile, the `1x0000000000000000000000000000000AA` dummy key always returns a successful validation. This entirely bypassed the bot protection mechanism if the application was deployed without the environment variable properly configured, allowing attackers to completely bypass rate limits and protections designed around Turnstile.
**Prevention:** Never use test keys or dummy keys as fallbacks for missing environment variables in production code. If a required security configuration or secret is missing, the application must explicitly "fail securely" by denying the request (e.g., throwing an error or returning a 500/403 status code) rather than silently disabling the protection.
