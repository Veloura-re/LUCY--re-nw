## 2024-11-02 - Biased Array Shuffling Vulnerability
**Vulnerability:** The codebase was using an insecure and statistically biased sorting pattern (`array.sort(() => Math.random() - 0.5)`) to shuffle arrays in a security-sensitive context (`app/api/school/timetable/auto-generate/route.ts`).
**Learning:** `Array.prototype.sort()` coupled with `Math.random()` does not produce a uniform distribution. Some permutations are far more likely to occur than others due to the underlying sorting algorithm implementations across different JS engines (e.g., Timsort in V8). This can lead to predictable patterns and reduce the effectiveness of randomization.
**Prevention:** When array shuffling is required, avoid the `array.sort(() => Math.random() - 0.5)` pattern. Instead, implement a Fisher-Yates shuffle algorithm and utilize a cryptographically secure random number generator, such as the `secureRandomInt` helper provided in `@/lib/security`, to ensure true randomness and uniform distribution.
